# Kabileshwar G — High-Tech Engineering Portfolio

A modern, responsive, animated personal engineering portfolio website for **Kabileshwar G**, a Computer Science and Engineering undergraduate specializing in **Artificial Intelligence and Machine Learning** at **SRM Institute of Science and Technology, Tiruchirappalli**.

All displayed content is strictly verified and transcribed directly from the official 2-page resume.

---

## 🚀 Key Visual & Interactive Features

- **6 Themes with Dynamic Theme Engine**:
  1. 👑 **Obsidian Gold (`dark`)**: Stealth near-black `#08090d` with warm gold accents (`#d4af37`).
  2. ⚡ **Titanium Slate (`light`)**: High-contrast minimal white/slate `#f8fafc` with amber accents (`#b45309`).
  3. 🌐 **Cyber Midnight (`navy`)**: Deep oceanic black `#030712` with electric azure/cyan (`#00f0ff`).
  4. 👾 **Synthwave Sunset (`synthwave`)**: Cosmic plum `#0a0414` with neon magenta/pink (`#f43f5e`).
  5. 🟢 **Matrix Terminal (`emerald`)**: Phosphor terminal black `#020b06` with radioactive neon green (`#10b981`).
  6. 🩸 **Blood Moon Cyber (`crimson`)**: Stealth carbon `#0d0407` with blazing scarlet ruby (`#ef4444`).
- **Floating HUD Command Dock**:
  - Replaces traditional static top navigation with a floating dynamic island capsule.
  - Position toggle: switch between **Floating Center-Top** or **Floating Vertical Side Dock**!
  - Adapts to a floating thumb-accessible pill dock on Mobile and iPad.
  - Active section indicator with smooth spring tracking.
- **Ambient Interactive Cyber Background (`CyberBackground.tsx`)**:
  - Particle constellation network with mouse magnetic connection lines.
  - Dynamic ambient plasma orbs reacting to active theme colors.
  - Subtle holographic perspective cyber grid.
- **Interactive Telemetry Command Terminal (`Hero.tsx`)**:
  - Live log streamer simulating real-time telemetry from MicroGuard Kafka traces, RL Bed Allocations, and RAG indexers.
  - Verified B.Tech CGPA (`8.02 / 10`, recent sem `8.6 / 10`) and IEEE Preprint paper metrics.
- **Spotlight Command Palette (`Ctrl + K` / `Cmd + K`)**:
  - Instant spotlight search across all 7 projects, 15 skill categories, internships, and education.
- **Synthesized UI Audio Engine**:
  - Built-in Web Audio API synthesizer generating clean, high-tech click and open feedback without any external audio files, with an instant Mute/Unmute toggle.
- **Widescreen & Responsive Architecture**:
  - Full-width `max-w-[1550px]` container layout across desktop, iPad Pro/Air, and mobile.
  - 3D hover lift, glowing border beams (`beam-card`), and cyber HUD brackets (`hud-bracket`).

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript (Strict `verbatimModuleSyntax`)
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS + custom CSS variables
- **Icons**: Lucide React + custom SVG icons
- **Audio**: Web Audio API (procedural oscillator feedback)
- **Canvas**: Dual interactive HTML5 Canvas engines (ambient constellation + telemetry node mesh)
